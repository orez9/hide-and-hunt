# Hide & Hunt

Chowany i manhunt w realu: mapa na żywo, kurcząca się strefa, power-upy i czat drużyny.
Za darmo, bez reklam. Android i iPhone grają razem w jednej grze.

**Strona gry:** https://hide-and-hunt-game.web.app

To repozytorium służy tylko do udostępniania plików instalacyjnych. Kod gry nie jest publiczny.

## Pobierz

Najnowsza wersja jest w zakładce **[Releases](https://github.com/orez9/hide-and-hunt/releases/latest)**.

| Plik | Dla kogo |
|---|---|
| `HideAndHunt-X.Y.Z-arm64.apk` | Android 7.0 lub nowszy, praktycznie każdy telefon z ostatnich lat |
| `HideAndHunt-X.Y.Z.apk` | Android, gdy plik wyżej się nie instaluje (starsze telefony) |
| `HideAndHunt-X.Y.Z-unsigned.ipa` | iPhone, samodzielna instalacja (Sideloadly lub AltStore) |

### Android

1. Pobierz plik APK na telefonie i otwórz go.
2. Telefon zapyta o zgodę na instalację z tego źródła: zezwól.
3. Uruchom Hide & Hunt i zezwól na lokalizację oraz powiadomienia.

Nowa wersja instaluje się na starą bez utraty ustawień.

### iPhone

Wydanie w App Store wymaga płatnego konta Apple, więc na razie plik IPA jest bez podpisu.
Można go zainstalować przez [Sideloadly](https://sideloadly.io) albo AltStore z własnym Apple ID.
Aplikację trzeba wtedy podpisywać ponownie co 7 dni.

## English

Real-life hide and seek / manhunt with a live map, a shrinking zone, power-ups and team chat.
Free, no ads. Download the latest APK (Android) or unsigned IPA (iPhone, sideload only) from
[Releases](https://github.com/orez9/hide-and-hunt/releases/latest). This repository only hosts the
installation files; the source code is not public.
